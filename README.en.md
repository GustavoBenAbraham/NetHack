# NetHack

[Português](README.pt-BR.md) | **English** | [Original upstream README](README)

NetHack is a dungeon-exploration game descended from Rogue and Hack. This fork follows the `NetHack-5.0` branch; its original README describes NetHack 5.0.0.

## Source and installation

The project is primarily C, with platform-specific build instructions. There is no single build command suitable for every supported platform.

Read the [original README](README), [file inventory](Files), [porting information](Porting) and [cross-compiling guide](Cross-compiling). The source tree contains platform instructions under `sys/` and window-system instructions under `win/`. The original README directs readers to the license in `dat/license`.

## Fork context

This is a fork of [NetHack/NetHack](https://github.com/NetHack/NetHack). Original authorship and license terms remain with the project. This overview does not claim that the fork owner developed NetHack.

The codebase provides opportunities to study C, game logic, portability and an established collaborative project.
