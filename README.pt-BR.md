# NetHack

**Português** | [English](README.en.md) | [README original](README)

NetHack é um jogo de exploração de masmorras descendente de Rogue e Hack. Este fork acompanha a branch `NetHack-5.0`; o README original desta revisão descreve o NetHack 5.0.0.

## Código e instalação

O projeto utiliza principalmente C, com instruções de compilação específicas por plataforma. Não há um comando único apropriado a todos os sistemas suportados.

Leia o [README original](README), o [inventário de arquivos](Files), as [informações de portabilidade](Porting) e o [guia de compilação cruzada](Cross-compiling). As instruções de plataforma ficam em `sys/`, e as de sistemas de janelas em `win/`. O README original orienta a leitura da licença em `dat/license`.

## Contexto do fork

Este repositório é um fork de [NetHack/NetHack](https://github.com/NetHack/NetHack). A autoria e os termos de licença continuam atribuídos ao projeto original. Esta apresentação não afirma que o proprietário do fork desenvolveu o NetHack.

O código oferece oportunidades de estudo de C, lógica de jogos, portabilidade e organização de um projeto colaborativo consolidado.
